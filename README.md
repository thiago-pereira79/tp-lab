## Sobre o projeto

**TP LAB** é o currículo digital, portfólio técnico e laboratório criativo de Thiago Pereira.

O projeto reúne trajetória profissional, estudos, experiências, projetos autorais e experimentos digitais em um único ambiente online, conectando desenvolvimento de software, UX Engineering, UI Design, Product Design e inteligência artificial aplicada.

Mais do que apresentar trabalhos concluídos, o TP LAB mostra diferentes etapas de aprendizado, construção e evolução profissional. Cada área foi organizada para tornar informações de carreira, formação e projetos mais claras, visuais e fáceis de navegar.

🔗 **Acesse o site:** https://www.tplab.com.br/

## Objetivo

O TP LAB foi desenvolvido para funcionar como uma apresentação profissional viva.

Em vez de reproduzir apenas o formato de um currículo tradicional, o projeto transforma experiências, estudos e trabalhos em uma experiência digital própria.

O site apresenta:

- trajetória profissional;
- formação acadêmica;
- cursos e certificações;
- projetos publicados;
- experimentos digitais;
- desenvolvimento web;
- UX Engineering;
- UI Design;
- Product Design;
- inteligência artificial aplicada;
- jogos e aplicações interativas;
- formas de contato profissional.

A proposta é permitir que recrutadores, profissionais, empresas e visitantes conheçam não apenas os projetos desenvolvidos, mas também as áreas de estudo, os aprendizados e a forma de pensar por trás de cada construção.

## Idiomas

O TP LAB oferece suporte a três idiomas:

- Português do Brasil;
- Inglês;
- Espanhol.

O idioma padrão é Português do Brasil.

A internacionalização é organizada por meio de uma estrutura própria localizada em `src/i18n`, contendo contexto global, traduções e um hook reutilizável para acesso aos textos traduzidos.

A preferência selecionada pode ser armazenada localmente no navegador, permitindo que o idioma seja preservado durante novas visitas.

As traduções são aplicadas aos elementos visíveis da interface, como:

- títulos;
- descrições;
- botões;
- navegação;
- informações profissionais;
- áreas de estudo;
- experiências;
- dados dos projetos;
- mensagens da interface.

Informações que não devem ser traduzidas permanecem preservadas, como:

- nomes próprios;
- nomes de marcas;
- nomes de projetos;
- endereços de e-mail;
- URLs;
- links externos;
- nomes de tecnologias;
- nomes de empresas.

## Decisões de UX/UI

O TP LAB foi estruturado para apresentar uma quantidade ampla de informações profissionais sem reproduzir a aparência de um currículo tradicional.

Entre as decisões de UX/UI aplicadas estão:

- arquitetura da informação organizada por áreas;
- hierarquia clara entre títulos, textos, informações complementares e ações;
- utilização de cards para separar conteúdos;
- navegação direta entre as principais seções;
- agrupamento de informações relacionadas;
- organização cronológica das experiências;
- apresentação visual dos projetos;
- uso de contraste para destacar conteúdos importantes;
- espaçamentos que facilitam a leitura;
- textos divididos em blocos menores;
- consistência entre botões, cards e elementos interativos;
- redução de excesso de informação em uma única área;
- adaptação da navegação para telas menores;
- feedback visual em elementos interativos;
- acesso direto aos projetos publicados;
- preservação da identidade visual em diferentes dispositivos.

A experiência prioriza clareza, organização e leitura fluida, permitindo que diferentes perfis de visitante naveguem pelo conteúdo de acordo com seus interesses.

## Pré-requisitos

Para executar o projeto localmente, é necessário possuir:

- Node.js;
- npm;
- Git, caso o projeto seja clonado de um repositório remoto.

## Instalação e execução local

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Acesse a pasta do projeto:

```bash
cd <PASTA_DO_PROJETO>
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local utilizado para acessar a aplicação pelo navegador.

Neste projeto, o endereço local configurado é:

```text
http://localhost:3000/
```

A porta pode variar se a configuração do script for alterada ou se a porta estiver indisponível.

## Scripts disponíveis

| Comando | Finalidade |
|---------|------------|
| `npm run dev` | Inicia o ambiente local de desenvolvimento com Vite |
| `npm run build` | Executa as verificações configuradas e gera o build de produção |
| `npm run preview` | Executa uma prévia local do build gerado |

Os scripts disponíveis são definidos no arquivo `package.json`.

Para gerar a versão de produção, execute:

```bash

```
